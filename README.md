# Communities Near the Benue River in Makurdi, Nigeria

## Project Question

Which communities in Makurdi LGA, Benue State, are located within 1 km of the Benue River?

## Study Area

Makurdi Local Government Area (LGA), Benue State, Nigeria.

## Project Overview

This project uses Geographic Information Systems (GIS) to identify communities in Makurdi LGA that are located within 1 km of the Benue River.

The project will use spatial proximity analysis by creating a 1 km buffer around the Benue River and identifying communities that fall within the buffer.

## Expected Output

A GIS map showing:

- The Benue River
- A 1 km buffer around the river
- Communities located within the 1 km buffer

## Project Scope

This project focuses only on the spatial proximity between communities and the Benue River.

Being located within 1 km of the river will be treated as a proximity measure and will not by itself be interpreted as evidence of flood risk or environmental risk.
